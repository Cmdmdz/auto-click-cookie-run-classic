# Auto Click AFK — Cookie Run Classic

สคริปต์ Python สำหรับคลิกปุ่มอัตโนมัติตอน AFK ในเกม Cookie Run Classic ที่เล่นผ่าน Emulator
(BlueStacks, LDPlayer ฯลฯ) บน PC โดยใช้การจับคู่รูปภาพ (template matching) หาปุ่มบนหน้าจอแล้วคลิกให้

รันบนเครื่องของคุณเองเท่านั้น (สคริปต์ควบคุมเมาส์จริงบน PC ที่รัน ไม่ใช่ใน sandbox)

## 1. เตรียมเครื่อง

ต้องมี Python 3.9+ ติดตั้งบนเครื่อง แล้วติดตั้งไลบรารีที่ใช้:

```bash
pip install pyautogui opencv-python numpy pillow
```

(บน Windows ไม่ต้องลงอะไรเพิ่ม, บน macOS อาจต้องอนุญาต Accessibility + Screen Recording ให้ Terminal
ใน System Settings > Privacy & Security)

## 2. เตรียมรูป Template ของปุ่ม

สร้างโฟลเดอร์ชื่อ `templates` ไว้ข้างๆ ไฟล์ `auto_click_afk.py` แล้วเก็บรูป "ปุ่ม" ที่ต้องการให้คลิกอัตโนมัติ
เป็นไฟล์ .png แยกไฟล์ต่อปุ่ม เช่น:

```
templates/
  confirm.png        # ปุ่มยืนยัน
  claim_reward.png    # ปุ่มรับรางวัล
  ok.png              # ปุ่ม OK
  skip.png            # ปุ่มข้าม
  battle.png           # ปุ่มเริ่มต่อสู้ / เข้าฉาก
```

### วิธีแคปรูปปุ่ม
1. เปิดเกมใน Emulator ให้ปุ่มที่ต้องการปรากฏบนหน้าจอ
2. ใช้เครื่องมือ Snipping Tool (Windows) หรือ Screenshot (macOS: Cmd+Shift+4) ครอบตัดเฉพาะบริเวณปุ่ม
   ให้ขอบชิดปุ่มพอดี ไม่ต้องเผื่อพื้นหลังเยอะ — ยิ่งครอบแม่นยิ่งจับคู่แม่น
3. เซฟเป็น .png ตั้งชื่อไฟล์ตามชื่อปุ่ม ใส่ในโฟลเดอร์ `templates/`
4. ทำซ้ำสำหรับทุกปุ่มที่ต้องการให้สคริปต์คลิกให้อัตโนมัติ

**ข้อควรระวัง:** ต้องแคปรูปตอนที่ขนาดหน้าต่าง Emulator และ % การซูมเหมือนกับตอนที่จะรันสคริปต์จริง
เพราะ template matching จับตามพิกเซล ถ้าขนาดหน้าจอเปลี่ยนไปจะจับไม่เจอ

## 3. ตั้งค่าก่อนใช้งาน

เปิดไฟล์ `auto_click_afk.py` แก้ค่าตรง `CONFIG = Config(...)` ได้ตามต้องการ เช่น:

- `dry_run: bool = True` — ทดสอบก่อน ให้สคริปต์บอกว่า "จะคลิกตรงไหน" โดยไม่คลิกจริง
  เมื่อมั่นใจว่าจับปุ่มถูกต้องแล้วค่อยเปลี่ยนเป็น `False` เพื่อคลิกจริง
- `match_confidence: float = 0.85` — ถ้าจับปุ่มไม่เจอ ให้ลองลดค่าลง (เช่น 0.75) แต่ถ้าจับผิดปุ่ม/คลิกมั่ว ให้เพิ่มค่าขึ้น
- `scan_interval` / `click_delay` — ความถี่ในการสแกนหน้าจอ และหน่วงเวลาหลังคลิกแต่ละครั้ง
- `region` — ถ้าอยากจำกัดสแกนเฉพาะกรอบหน้าต่าง Emulator ใส่เป็น `(left, top, width, height)`
  (พิกัดหามาจาก mouse position เช่นใช้ `python -c "import pyautogui; print(pyautogui.position())"`
  เอาเมาส์ไปชี้มุมซ้ายบน/ขวาล่างของหน้าต่างแล้วอ่านพิกัด)
- `priority_order` — ลำดับความสำคัญของปุ่ม ถ้าเจอหลายปุ่มพร้อมกันในรอบเดียว จะคลิกปุ่มที่อยู่ลำดับแรกก่อน

## 4. รันสคริปต์

```bash
python auto_click_afk.py
```

- เปิดหน้าต่างเกมให้อยู่ในมุมมองปกติ (ไม่ย่อ ไม่บัง)
- ถ้า `dry_run = True` จะเห็น log บอกว่าเจอปุ่มอะไร ที่พิกัดไหน โดยไม่คลิกจริง — ใช้เช็คความแม่นยำก่อน
- เมื่อพร้อมใช้งานจริง เปลี่ยน `dry_run = False` แล้วรันใหม่ สคริปต์จะรอ 5 วินาทีให้สลับหน้าต่างไปเกมก่อนเริ่มคลิก
- กด `Ctrl+C` ที่หน้าต่าง terminal เพื่อหยุดเมื่อไหร่ก็ได้

## Troubleshooting

| ปัญหา | วิธีแก้ |
|---|---|
| จับปุ่มไม่เจอเลย | ลด `match_confidence`, เช็คว่าแคปรูปตอนขนาดจอ/ซูมเดียวกับตอนรัน |
| คลิกผิดตำแหน่ง/ผิดปุ่ม | เพิ่ม `match_confidence`, แคป template ให้ครอบเฉพาะปุ่มแม่นๆ ไม่เผื่อพื้นหลัง |
| คลิกถี่/รัวเกินไป | เพิ่ม `click_delay` และ `scan_interval` |
| สคริปต์ควบคุมเมาส์ไม่ได้ (macOS) | ให้สิทธิ์ Accessibility กับ Terminal/IDE ใน System Settings > Privacy & Security |
| หน้าจอ scale ผิด (Windows High-DPI) | ปิด DPI scaling ของ Emulator หรือปรับ scaling ของ Windows เป็น 100% ก่อนแคป template |
